# resume apply

`resume-apply` 是一个用于中国大陆求职场景的通用 AI agent 工作流。它不是 Codex 专属；Codex、Claude Code，以及其它能够读取 Markdown 指令的 AI 工具，都可以按这个仓库里的说明使用。

它会引导用户选择一个专门存放简历的文件夹，读取简历内容，收集岗位偏好，从招聘平台和公司官网招聘页中筛选匹配岗位，生成待投递队列，并在用户确认队列后自动投递队列中安全可投的岗位。

## 适用于哪些 AI 工具

- **Codex / OpenAI agents**：读取 `SKILL.md`，并可使用 `agents/openai.yaml` 中的界面元数据。
- **Claude Code**：先读 `CLAUDE.md`，再按 `SKILL.md` 执行。
- **其它 AI agent**：先读 `AGENTS.md`，再按 `SKILL.md`、`references/` 和 `scripts/` 使用。
- **不能执行命令的工具**：仍可按工作流完成岗位筛选、队列确认和投递记录，只是需要用户手动提供简历内容、JD 文本或投递结果。

## 它能做什么

- 首次使用时引导用户设置简历文件夹，不绑定 Windows 或 macOS 的固定路径。
- 将脚本配置默认保存在更通用的 `~/.resume-apply/settings.json`，并兼容旧的 Codex 配置路径。
- 从用户选择的简历文件夹中读取简历。
- 支持严格匹配、平衡匹配、广泛探索三种岗位筛选模式。
- 根据简历证据和用户偏好评估 JD 匹配度。
- 自动推荐每个岗位使用的简历版本，并在队列确认页展示。
- 生成待投递队列，用户浏览队列后可一次确认批量投递。
- 队列确认后，对安全可投的岗位自动提交；每投递一个岗位后等待 30 秒。
- 遇到额外表单、验证码、扫码登录、隐私授权、测评、页面不一致等情况，自动标记为需人工处理并继续处理其它岗位。
- 同一平台连续 5 次异常后，暂停该平台本轮批量投递。
- 生成结构化投递记录和完成报告。

## 安全边界

这个工作流不是无边界的自动海投工具，而是一个“队列确认后批量投递”的求职助手。

- 不保存招聘网站账号密码。
- 不绕过验证码、短信验证、扫码登录、反自动化检查或访问限制。
- 如果网站明确禁止自动化操作，只生成队列和人工操作建议，不自动投递。
- 需要用户手动登录招聘平台或公司招聘系统。
- 用户可以一次确认投递队列，但不安全岗位会自动转为需人工处理。
- 将简历和投递记录视为个人隐私数据处理。

## 队列状态

投递记录使用这些状态：

- `queued`：已进入待投递队列。
- `submitted`：已提交。
- `needs_manual`：需要人工处理。
- `skipped`：已跳过。
- `failed`：处理失败。
- `paused`：本轮暂停。

## 典型使用方式

让你的 AI 工具读取本仓库，并要求它使用 `resume-apply` 工作流，根据你的简历筛选适合的中国大陆岗位，生成待投递队列，并在你确认队列后批量投递安全可投的岗位。

第一次使用时，工作流会要求你创建并提供一个专门存放简历的文件夹。后续再次使用时，如果工具支持本地配置读取，会默认复用这个文件夹。
